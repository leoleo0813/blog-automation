<p>전문투자자는 이 최소투자금액 규정에서 제외됩니다. 여기서 말하는 최소투자금액은 개인·법인 일반투자자가 일반 사모펀드에 가입할 때 적용되는 기준입니다.</p>

<h2 style="border-left:6px solid #673ab7;padding-left:12px;margin-top:36px;">일반투자자가 가입하는 방법</h2>

<p>일반투자자가 일반 사모펀드에 가입하려면 위 최소투자금액 요건을 충족해야 하고, 증권사나 은행 등 판매사를 통해 가입 절차를 밟습니다. 전문투자자로 등록돼 있다면 최소투자금액 제한 없이 가입할 수 있습니다.</p>

<ul style="line-height:1.9;">
  <li>증권사·은행 등 사모펀드 판매사를 통한 가입(가장 일반적인 경로)</li>
  <li>전문투자자 등록 시 최소투자금액 제한 면제(단, 별도 요건 충족 필요)</li>
  <li>사모재간접펀드(사모펀드에 재간접 투자하는 공모펀드) 가입으로 소액 접근(단, 이 경우 사모펀드가 아닌 공모펀드 상품에 투자하는 것)</li>
</ul>

<p>단, 어떤 판매사가 어떤 상품을 취급하는지, 실제 수익률이 얼마인지는 이 글에서 다루지 않습니다. 특정 상품의 매수를 권하는 것이 아니라 제도 자체를 설명하는 글이기 때문입니다.</p>

<h2 style="border-left:6px solid #673ab7;padding-left:12px;margin-top:36px;">사모펀드 세금 계산법</h2>

<p>사모펀드에서 발생한 배당·이자 성격의 수익에는 <mark>배당소득세 15.4%(소득세 14%+지방소득세 1.4%)</mark>가 원천징수됩니다. 배당소득세의 구체적인 근거와 계산 방식은 <a href="https://sensitiveboss3.tistory.com/entry/dividend-income-tax" target="_blank" rel="noopener">배당소득세 얼마 떼나</a> 글에서 자세히 다뤘습니다.</p>

<div style="background:#f6f6f4;border-left:4px solid #999;padding:14px 18px;margin:20px 0;line-height:1.9;">
  <b>계산 예시 (가상 사례)</b>
  <p style="margin:8px 0 0 0;">가상의 투자자 B씨가 사모펀드에 3억원을 투자해 배당·이자 성격 수익 2,000만원이 발생했다고 가정하면, 원천징수세액은 2,000만원 × 15.4% = 308만원입니다. 세후 실수령액은 1,692만원입니다.</p>
</div>

<p>그런데 이 2,000만원이 다른 이자·배당소득과 합쳐 연 2,000만원을 넘으면 금융소득종합과세 대상이 됩니다. 2천만원 기준을 판단하는 구체적인 절차와 계산 예시는 <a href="https://sensitiveboss3.tistory.com/entry/financial-income-comprehensive-tax" target="_blank" rel="noopener">금융소득종합과세 2천만원 기준 확인법</a>에서 자세히 다루고 있으니 함께 참고하세요.</p>

<h2 style="border-left:6px solid #673ab7;padding-left:12px;margin-top:36px;">헷갈리기 쉬운 부분</h2>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">사모펀드와 헤지펀드는 같은 말인가요</summary>
  <p style="margin:10px 0 0 0;">완전히 같지는 않습니다. 국내에서는 사모펀드를 경영참여형(PEF)과 전문투자형(과거 헤지펀드로 불리던 유형)으로 나누는데, 둘 다 일반 사모펀드 규제를 받는 넓은 의미의 사모펀드에 속합니다.</p>
</details>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">최소투자금액 3억원 규정은 모든 사모펀드에 적용되나요</summary>
  <p style="margin:10px 0 0 0;">일반투자자가 가입하는 일반 사모펀드에 적용됩니다. 전문투자자는 이 최소투자금액 규정에서 제외되며, 별도의 전문투자자 등록 요건을 충족해야 합니다.</p>
</details>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">사모펀드는 원금 손실 위험이 없나요</summary>
  <p style="margin:10px 0 0 0;">아닙니다. 사모펀드는 예금자보호 대상이 아니고, 운용 실패나 투자 기업의 부실로 원금 손실이 발생할 수 있습니다. 고수익을 추구하는 만큼 그에 상응하는 위험도 함께 있습니다.</p>
</details>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">사모펀드는 중도 환매가 자유로운가요</summary>
  <p style="margin:10px 0 0 0;">대체로 자유롭지 않습니다. 사모펀드는 기업 지분이나 비상장 자산처럼 즉시 현금화하기 어려운 자산에 투자하는 경우가 많아, 펀드별로 정해진 만기나 환매 제한 기간이 있는 경우가 일반적입니다.</p>
</details>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">사모재간접펀드로 가입하면 최소투자금액 3억원이 필요 없나요</summary>
  <p style="margin:10px 0 0 0;">그렇습니다. 사모재간접펀드 자체는 공모펀드 형태로 설계돼 있어 소액으로도 가입할 수 있습니다. 단, 이 경우 사모펀드에 직접 투자하는 것이 아니라 사모펀드에 재투자하는 공모펀드 상품에 투자하는 구조라는 점을 구분해야 합니다.</p>
</details>
