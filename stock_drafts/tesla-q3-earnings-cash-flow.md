<h2 id="sec-1" style="scroll-margin-top:72px;border-left:6px solid #16a34a;padding-left:12px;margin-top:36px;">번 현금에서 설비투자를 빼면 얼마가 남나요</h2>

<div style="background:#f8f9fa;border:1px solid #dee2e6;border-radius:8px;padding:14px 18px;margin:16px 0;line-height:1.9;">

<h2 id="sec-2" style="scroll-margin-top:72px;border-left:6px solid #16a34a;padding-left:12px;margin-top:36px;">순이익은 줄었는데 현금은 왜 남았을까요</h2>

<p>순이익은 7억 8,700만 달러로 줄었지만 영업활동 현금흐름은 약 63억 달러로, 둘의 차이가 약 8배예요. 순이익은 감가상각처럼 현금이 나가지 않는 비용을 뺀 뒤의 값이고, 현금흐름은 실제로 들어오고 나간 돈이라 서로 다르게 움직일 수 있어요.</p>

<p>이익이 줄어든 폭과 투자가 늘어난 폭을 같이 놓으면 이번 분기의 성격이 보여요. 순이익은 42.6% 줄었고 설비투자는 110% 늘었는데, 매출은 0.2%밖에 안 변했어요.</p>

<p>순이익이 정확히 어떤 항목 때문에 현금과 8배 벌어졌는지는 분기보고서(10-Q)의 현금흐름표에 나와요. <a href="https://www.sec.gov/cgi-bin/browse-edgar?action=getcompany&amp;CIK=0001318605&amp;type=10-Q" target="_blank" rel="noopener">SEC EDGAR의 테슬라 10-Q 목록</a>에서 가장 위 보고서를 열고 현금흐름표 항목(감가상각, 운전자본 변동)을 보면 됩니다.</p>

<div style="background:#fffbeb;border:1px solid #f59e0b;border-radius:8px;padding:14px 18px;margin:16px 0;">
  <strong>💡 비GAAP EPS를 볼 때</strong>
  <p style="margin:8px 0 0 0;">0.48달러는 회사 기준 조정값이고 회계 기준(GAAP) 순이익은 7억 8,700만 달러예요. 시장 예상 EPS도 0.43달러와 0.45달러로 보도가 엇갈려서 이 글은 예상치와의 비교를 쓰지 않아요. 계산 방식은 <a href="https://sensitiveboss3.tistory.com/entry/eps-meaning-calculation" target="_blank" rel="noopener">EPS 뜻과 계산 방법</a>, 예상치 보는 법은 <a href="https://sensitiveboss3.tistory.com/entry/consensus-estimate-check-guide" target="_blank" rel="noopener">컨센서스 뜻과 확인 방법</a> 글에 있어요.</p>

<h2 id="sec-3" style="scroll-margin-top:72px;border-left:6px solid #16a34a;padding-left:12px;margin-top:36px;">인도량·생산량·에너지저장 표로 읽는 법</h2>

<p>분기 인도량은 재무제표보다 먼저 나와요. 이번에는 분기가 끝난 직후인 10월 2일에 인도량이 보도됐고, 재무 결과는 3주쯤 뒤인 10월 21일에 나왔어요.</p>

<p>인도량이 생산량보다 22,141대 많다는 건 재고에서 그만큼 꺼내 팔았다는 뜻이에요. <mark>매출이 거의 그대로인 이유 중 하나는 차량 인도가 2.1% 줄었기 때문이고, 에너지저장이 전년보다 약 10% 늘어 일부를 받쳤어요.</mark></p>

<p>에너지저장 설치량 13.7GWh는 전분기보다 조금 늘었지만 역대 최고치(14.2GWh)에는 0.5GWh 못 미쳐요. 한 곳은 시장 예상(약 15.9GWh)보다 낮다고 평가했고, 다른 곳은 역대 두 번째로 좋은 분기라고 적어서 평가가 갈려요.</p>

<h2 id="sec-4" style="scroll-margin-top:72px;border-left:6px solid #16a34a;padding-left:12px;margin-top:36px;">테슬라 실적이 주식 투자자에게 왜 중요한가</h2>

<p>테슬라 실적은 이익과 현금이 서로 다른 이야기를 할 때 무엇을 먼저 볼지 보여 주는 사례예요. 주가가 오를지 내릴지를 알려 주는 숫자는 아니고, 시장이 어떤 숫자에 반응하는지 확인하는 재료예요.</p>

<ul style="line-height:1.9;">
  <li>현금 경로: 투자 규모가 큰 기업은 이익보다 잉여현금흐름이 투자를 감당할 여력을 더 직접 보여 줘요. 이번처럼 예상한 유출 대신 흑자가 나오면 투자 부담 우려가 줄었다고 해석하는 시각이 있어요.</li>
  <li>투자 경로: 설비투자가 매출의 16.9%로 전년(약 8.0%)의 두 배예요. 투자가 앞으로 매출과 이익으로 이어질지는 분기마다 계속 확인해야 해요.</li>
  <li>수요 경로: 인도량은 매출보다 먼저 나오는 숫자라서, 인도 − 생산 차이로 재고가 줄었는지 늘었는지를 같이 봐요.</li>
</ul>

</div>

<h2 id="sec-5" style="scroll-margin-top:72px;border-left:6px solid #16a34a;padding-left:12px;margin-top:36px;">실적 읽고 나서 남는 궁금증</h2>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">테슬라 3분기 실적은 언제 발표됐나요?</summary>
  <p style="margin:10px 0 0 0;">2026년 10월 21일(미국 현지 기준)에 발표됐어요. 차량 인도량은 그보다 앞선 10월 2일에 먼저 공개됐어요.</p>
</details>
<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">잉여현금흐름은 얼마였나요?</summary>
  <p style="margin:10px 0 0 0;">약 15억 3천만 달러 흑자예요. 영업활동 현금흐름 약 63억 달러에서 설비투자 47억 3천만 달러를 뺀 값이에요.</p>
</details>
<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">주당순이익 0.48달러는 어떤 기준인가요?</summary>
  <p style="margin:10px 0 0 0;">회사가 조정해서 발표하는 비GAAP 기준이에요. 전년 동기 0.50달러보다 4% 낮고, 회계 기준 순이익은 7억 8,700만 달러로 42.6% 줄었어요.</p>
</details>
<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">실적이 좋으면 주가도 오르나요?</summary>
  <p style="margin:10px 0 0 0;">단정할 수 없어요. 주가는 숫자 자체보다 시장이 미리 예상한 값과의 차이, 설비투자 같은 비용 전망에 함께 반응해서 같은 숫자에도 움직임이 엇갈릴 수 있어요.</p>
</details>
