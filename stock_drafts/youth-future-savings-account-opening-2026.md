<h2 id="sec-4" style="scroll-margin-top:72px;border-left:6px solid #2e8b57;padding-left:12px;margin-top:36px;">우대형 12%를 끝까지 받는 조건</h2>

<p>우대형으로 가입했다고 끝이 아니에요. 금융위원회 발표 기준으로 <mark>만기 한 달 전까지 중소기업에서 29개월 이상 일하고, 이직은 2번 이하</mark>여야 12%가 유지돼요. 이 조건을 못 채우면 만기 때 일반형(6%)으로 바뀌어요.</p>

<p>월 50만원을 넣었다면 이 차이가 108만원이에요. 3년 안에 대기업이나 공공기관으로 옮길 계획이 있다면, 우대형 기여금 전부를 믿고 계획을 세우기보다 일반형 금액(1,908만원)을 기준으로 잡아 두는 편이 안전해요.</p>

<h2 id="sec-5" style="scroll-margin-top:72px;border-left:6px solid #2e8b57;padding-left:12px;margin-top:36px;">청년도약계좌 가입자가 할 일</h2>

<p>청년도약계좌는 2025년 말로 신규 가입이 끝났고, 두 상품은 함께 가질 수 없어요. 도약계좌가 있는 사람이 2차 심사를 통과했다면 순서가 중요해요.</p>

<ol style="line-height:1.9;">
  <li>11월 16~27일 사이에 <b>청년미래적금 계좌를 먼저</b> 열어요.</li>
  <li>그다음 도약계좌 은행에서 <b>"청년미래적금 가입 목적의 청년도약계좌 특별중도해지"</b>를 신청해요.</li>
</ol>

<p>순서를 거꾸로 해서 도약계좌를 먼저 일반 해지하면 그동안 쌓인 기여금과 비과세 혜택을 잃을 수 있어요.</p>

<p>3년 뒤 받은 목돈을 굴릴 때도 세금 혜택이 있는 계좌가 있어요. <a href="https://sensitiveboss3.tistory.com/entry/isa-limit-benefit" target="_blank" rel="noopener">ISA 계좌 한도와 비과세 혜택</a>, 연금 저축과 비교한 <a href="https://sensitiveboss3.tistory.com/entry/irp-isa-account-difference" target="_blank" rel="noopener">IRP와 ISA 차이</a>를 참고하면 만기 뒤 계획을 미리 세울 수 있어요.</p>

<h2 id="sec-6" style="scroll-margin-top:72px;border-left:6px solid #2e8b57;padding-left:12px;margin-top:36px;">청년미래적금 Q&amp;A 5개</h2>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">청년미래적금 2차 계좌 개설 기간은 언제인가요</summary>
  <p style="margin:10px 0 0 0;">11월 16일부터 27일까지이고 토요일·일요일은 안 돼요. 최종 가입 가능 안내를 받은 사람만 신청한 은행 앱에서 열 수 있고, 기간이 지나면 가입할 수 없어요.</p>
</details>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">청년미래적금 2차 결과는 언제 나오나요</summary>
  <p style="margin:10px 0 0 0;">사전심사 결과는 10월 30일~11월 2일, 최종 결과는 11월 12~13일에 개별 안내돼요. 사전심사와 이의신청 날짜는 금융위원회가 밝힌 잠정 일정이라 조금 바뀔 수 있어요.</p>
</details>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">월 50만원 넣으면 만기 때 얼마 받나요</summary>
  <p style="margin:10px 0 0 0;">이자를 빼면 원금 1,800만원에 일반형은 기여금 108만원을 더해 1,908만원, 우대형은 216만원을 더해 2,016만원이에요. 여기에 은행 이자가 비과세로 붙어요.</p>
</details>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">우대형이 일반형으로 바뀔 수도 있나요</summary>
  <p style="margin:10px 0 0 0;">네. 만기 한 달 전까지 중소기업 재직 29개월 이상, 이직 2회 이하를 채우지 못하면 만기 때 일반형으로 바뀌어요. 사전심사에서 유형이 신청과 다르게 나왔다면 이의신청 기간에 바로잡을 수 있어요.</p>
</details>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">청년도약계좌가 있으면 어떻게 하나요</summary>
  <p style="margin:10px 0 0 0;">두 상품은 함께 가질 수 없어요. 2차 심사를 통과했다면 11월 16~27일에 청년미래적금 계좌를 먼저 열고, 그다음 청년미래적금 가입 목적의 청년도약계좌 특별중도해지를 신청해요.</p>
</details>
