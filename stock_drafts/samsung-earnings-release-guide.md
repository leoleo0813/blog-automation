  <li>전 분기 대비 증감률: 최근 흐름의 방향을 봅니다.</li>
  <li>영업이익률: 매출 대비 이익 체력을 봅니다.</li>
  <li>컨센서스 대비: 시장이 기대한 수준과 얼마나 달랐는지 봅니다.</li>
</ul>

<p><mark>2분기에는 영업이익이 컨센서스를 웃돌았는데도 시장 기대가 더 높았다는 보도와 함께 주가가 내렸습니다.</mark> 실적 숫자와 가격 반응은 별개로 움직일 수 있다는 사례입니다.</p>

<p>배당처럼 실적과 맞물린 일정은 <a href="https://sensitiveboss3.tistory.com/entry/samsung-electronics-dividend-q3-2026" target="_blank" rel="noopener">삼성전자 배당금 3분기 글</a>에서, 같은 주에 겹칠 수 있는 파생 만기는 <a href="https://sensitiveboss3.tistory.com/entry/quadruple-witching-day-2026" target="_blank" rel="noopener">네마녀의 날 일정 글</a>에서 따로 볼 수 있습니다.</p>

<h2 id="sec-6" style="scroll-margin-top:72px;border-left:6px solid #0f766e;padding-left:12px;margin-top:36px;">자주 오는 질문 다섯 가지</h2>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">잠정실적과 확정실적 숫자가 다르면 어느 쪽이 맞습니까?</summary>
  <p style="margin:10px 0 0 0;">확정실적이 최종입니다. 잠정은 감사 전 집계라 미세하게 조정될 수 있고, 이 차이는 확정 공시나 컨퍼런스콜 자료에서 바로 대조할 수 있습니다.</p>
</details>
<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">실적 발표 시각에 매매가 막히나요?</summary>
  <p style="margin:10px 0 0 0;">막히지 않습니다. 공시는 정규장 시작 전후에 나오는 경우가 많고, 발표 뒤 가격은 평소처럼 형성됩니다.</p>
</details>
<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">컨퍼런스콜은 일반 투자자도 볼 수 있습니까?</summary>
  <p style="margin:10px 0 0 0;">삼성전자 IR 페이지의 안내에 따라 사전 질문 접수와 시청 방법이 공지됩니다. 일정은 분기마다 공고로 바뀝니다.</p>
</details>
<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">영업이익이 컨센서스보다 높으면 주가도 오릅니까?</summary>
  <p style="margin:10px 0 0 0;">그렇지 않은 사례가 있습니다. 2분기에는 영업이익이 컨센서스를 웃돌았는데도 시장이 더 높은 숫자를 기대했다는 보도와 함께 주가가 내렸습니다.</p>
</details>
<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
