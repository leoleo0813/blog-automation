<h2 id="sec-1" style="scroll-margin-top:72px;border-left:6px solid #e0703a;padding-left:12px;margin-top:36px;">연말정산 미리보기 기간과 들어가는 곳</h2>

<p>미리보기는 1~9월 실제 카드 사용액과 지난 연말정산 때 넣은 공제 정보를 불러오고, 10~12월 예상 사용액은 직접 입력해서 내년 초 환급액이나 추가 납부액을 계산해 줘요.</p>

<ul style="line-height:1.9;">
  <li><b>기간:</b> 2026년 10월 28일 ~ 12월 18일로 안내돼 있어요(작년에는 11월 5일에 열렸어요).</li>
  <li><b>들어가는 곳:</b> <a href="https://www.hometax.go.kr" target="_blank" rel="noopener">홈택스</a> → 장려금·연말정산·기부금 → 편리한 연말정산 → 연말정산 미리보기.</li>
  <li><b>결과는 예상치:</b> 실제 자료는 2027년 1월 간소화 서비스에서 확정돼요.</li>
</ul>

<h2 id="sec-3" style="scroll-margin-top:72px;border-left:6px solid #e0703a;padding-left:12px;margin-top:36px;">남은 두 달 결제 수단에 따른 차이</h2>

<p>소득공제 105만원 차이는 세금으로 바꾸면 내 세율만큼이에요. 이 사람이 지방소득세 포함 16.5% 구간이라고 가정하면 <mark>약 17만3천원</mark>을 더 돌려받는 셈이에요. 반대로 미리보기에서 아직 문턱 아래로 나왔다면, 문턱까지는 어떤 카드로 써도 공제가 0이니 포인트·할인이 많은 신용카드가 나아요.</p>

  <p style="margin:10px 0 0 0;">1년 카드 사용액이 총급여의 25%를 넘긴 금액부터 받아요. 총급여 4,000만원이면 1,000만원을 넘긴 금액에 신용카드 15%, 체크카드·현금영수증 30%, 전통시장·대중교통 40%를 곱해요.</p>
</details>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">신용카드와 체크카드 중 뭘 써야 유리한가요</summary>
  <p style="margin:10px 0 0 0;">총급여의 25%까지는 신용카드 사용분부터 문턱을 채우고 공제가 0원이라 혜택 많은 신용카드가 나아요. 25%를 넘긴 뒤 쓰는 돈은 체크카드·현금영수증이 30%로 신용카드 15%의 두 배예요.</p>
</details>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">2026년 카드 소득공제 한도는 얼마인가요</summary>
  <p style="margin:10px 0 0 0;">총급여 7,000만원 이하는 자녀 없음 300만원, 자녀 1명 350만원, 2명 이상 400만원이에요. 7,000만원 초과는 250만원, 275만원, 300만원이에요. 전통시장·대중교통 사용분은 별도 추가 한도가 있어요.</p>
</details>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">미리보기 결과대로 환급받나요</summary>
  <p style="margin:10px 0 0 0;">아니요. 1~9월 실제 자료와 내가 넣은 10~12월 예상값으로 계산한 참고값이에요. 실제 금액은 2027년 1월 간소화 자료와 회사 연말정산에서 확정돼요.</p>
</details>
