<p>10월물 옵션은 10월 8일 오후 3시 20분에 거래가 끝나고, 현금 정산은 다음 거래일인 10월 12일 월요일에 이뤄집니다. 10월 9일 금요일이 한글날로 증시가 쉬고 이어서 주말이기 때문입니다. 휴장 달력은 <a href="https://sensitiveboss3.tistory.com/entry/stock-market-holidays-2026-remaining" target="_blank" rel="noopener">주식 휴장일 2026 남은 4일과 연말 폐장일</a> 글에 있습니다.</p>

<ol>
  <li>10월 8일(목) 오후 3시 20분: 10월물 거래 종료, 권리행사도 이날까지</li>
  <li>10월 9일(금), 10~11일(토·일): 휴장</li>
  <li>10월 12일(월): 최종결제일, 현금으로 정산</li>
</ol>

<p>11월물과 12월물은 휴장이 끼지 않아 바로 다음 날 정산됩니다. <mark>정산일이 3일 뒤로 밀리는 달은 10월물뿐입니다.</mark></p>

<h2 id="sec-4" style="scroll-margin-top:72px;border-left:6px solid #047857;padding-left:12px;margin-top:36px;">위클리 옵션은 둘째 목요일에 왜 빠지나요</h2>

<p><mark>둘째 목요일에는 월물 옵션이 만기를 맞기 때문에 같은 날 끝나는 목요일 위클리 옵션은 따로 상장하지 않습니다.</mark> 겹치는 상품을 피하려는 구조입니다. 이 구조는 <a href="https://edaily.co.kr/News/Read?mediaCodeNo=257&amp;newsId=02191046622621760" target="_blank" rel="noopener">이데일리의 위클리옵션 상장 보도</a>에 나옵니다.</p>

<ul>
  <li>월요일 만기 상품: 매주 월요일, 휴장이면 순연</li>
  <li>목요일 만기 상품: 둘째 목요일을 뺀 매주 목요일, 휴장이면 앞당김</li>
  <li>코스피200 위클리옵션은 2019년 9월 23일에 상장됐습니다.</li>
</ul>

<p>10월 둘째 주에는 목요일 위클리 상품이 없고 월물 옵션만 8일에 끝납니다. 같은 주에 두 만기가 겹치지 않아 날짜를 세기가 오히려 단순합니다.</p>

<h2 id="sec-5" style="scroll-margin-top:72px;border-left:6px solid #047857;padding-left:12px;margin-top:36px;">주식 투자자에게 만기일이 중요한 이유</h2>

<p>옵션 만기일은 옵션을 정리하려는 거래가 장 마감 무렵에 몰릴 수 있는 날이라, 주식만 거래해도 마감 직전 가격 움직임에 영향을 받을 수 있습니다. 옵션 보유자가 만기 전에 포지션을 정리하거나 헤지용 주식·선물 거래를 조정하면 코스피200 구성 종목의 거래량이 평소와 달라질 수 있기 때문입니다.</p>

<p>이 효과는 선물까지 함께 끝나는 분기 달에 더 크게 거론됩니다. 10월 8일처럼 옵션만 끝나는 달은 구조가 단순한 대신 영향이 작을 때도 있고 아닐 때도 있어서, 방향을 미리 말할 수는 없습니다.</p>

<ul>
  <li>만기일 장 막판에는 평소보다 호가가 빨리 바뀔 수 있다는 점</li>
  <li>분기 달(12월, 3월)과 비분기 달(10월, 11월, 1월, 2월)은 구조가 다르다는 점</li>
  <li>정산일은 거래일 기준이라 휴장이 끼면 며칠 뒤로 밀린다는 점</li>
</ul>

<h2 id="sec-6" style="scroll-margin-top:72px;border-left:6px solid #047857;padding-left:12px;margin-top:36px;">달력 보다 보면 나오는 질문</h2>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">옵션만기일이 휴장일이면 언제로 바뀌나요?</summary>
  <p style="margin:10px 0 0 0;">직전 영업일로 앞당겨집니다. 증권사 상품 안내는 휴일인 경우 순차적으로 앞당긴다고 적고 있습니다.</p>
</details>
<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">만기일에 들고 있는 옵션은 어떻게 정산되나요?</summary>
  <p style="margin:10px 0 0 0;">결제 방법은 현금결제이고 최종결제일은 최종거래일 다음 거래일입니다. 10월물은 10월 8일이 최종거래일이라 정산은 10월 12일(월)입니다.</p>
</details>
<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">옵션만기일과 네마녀의 날은 같은 날인가요?</summary>
  <p style="margin:10px 0 0 0;">분기 달인 3·6·9·12월에는 같은 날입니다. 나머지 달은 옵션만 만기라 네마녀의 날이 아닙니다.</p>
</details>
<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">위클리 옵션은 만기일이 따로 있나요?</summary>
  <p style="margin:10px 0 0 0;">있습니다. 월요일 만기 상품은 매주 월요일, 목요일 만기 상품은 둘째 목요일을 뺀 매주 목요일에 끝납니다.</p>
</details>
<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">주식만 거래하는데 만기일을 알아야 하나요?</summary>
  <p style="margin:10px 0 0 0;">직접 옵션을 거래하지 않아도 장 마감 무렵 지수와 거래량이 평소와 다르게 움직이는 날로 거론됩니다. 다만 매번 그런 것은 아니라서, 그날은 장 막판 가격 변동이 커질 수 있다는 정도로 알아 두면 충분합니다.</p>
</details>
<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">정확한 만기일 공지는 어디서 보나요?</summary>
  <p style="margin:10px 0 0 0;">한국거래소의 파생상품 상품명세와 휴장일 공지가 기준입니다. 증권사 선물옵션 상품 안내 페이지에도 같은 규칙이 정리돼 있습니다.</p>
</details>
