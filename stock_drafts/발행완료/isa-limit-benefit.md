<p>ISA 계좌는 <mark>1년에 2,000만원, 계좌 전체로 1억원</mark>까지 넣을 수 있습니다. 이자·배당 같은 순소득은 일반형 200만원, 서민형·농어민형 400만원까지 세금이 없습니다.</p>

<h2 id="sec-2" style="scroll-margin-top:72px;border-left:6px solid #3d8f6b;padding-left:12px;margin-top:36px;">남은 납입한도 이월 계산법</h2>

<p>위 표는 가상의 납입 사례이고, 1년차 500만원 → 2년차 최대 3,500만원은 "연 2,000만원 + 이월 1,500만원" 산술입니다. 3년차에는 "연 2,000만원 + 이월 3,000만원"으로 5,000만원까지 넣을 수 있습니다. 총한도 1억원에서 이미 낸 1,000만원이 빠지므로 가입 기간 전체로 더 넣을 수 있는 금액은 9,000만원입니다.</p>

<p>금융소득이 연 2,000만원을 넘어 종합과세 대상이 되는 사람은 이 차이가 더 커집니다. 종합과세 기준은 <a href="https://sensitiveboss3.tistory.com/entry/financial-income-comprehensive-tax">금융소득종합과세 글</a>에서 따로 계산합니다.</p>

<h2 id="sec-4" style="scroll-margin-top:72px;border-left:6px solid #3d8f6b;padding-left:12px;margin-top:36px;">ISA 한도가 올랐다는 이야기가 퍼진 이유</h2>

<p>기존 ISA 한도가 아니라 2026년 세제개편안에 담긴 새 상품의 한도가 섞여 퍼진 것입니다.</p>

<div style="background:#fff8e6;border-left:4px solid #e0a800;padding:14px 18px;margin:20px 0;">
  <b>혼동이 생긴 경로</b>
  <ul style="margin:8px 0 0 0;padding-left:20px;line-height:1.9;">
    <li>2026년 세제개편안에 <b>"생산적금융 ISA"</b>라는 별도 상품 신설 계획이 들어갔습니다.</li>
    <li>이 상품의 한도(연 2,000만원, 총 2억원)와 기존 ISA 한도가 구분 없이 섞여 "한도가 올랐다"로 퍼졌습니다.</li>
    <li>기존 일반형·서민형·농어민형 ISA의 한도는 이번 개편안으로 바뀌지 않습니다.</li>
  </ul>
</div>

<p>해설 글마다 8월 초 발표안과 9월 1일 확정 정부안의 내용을 섞어 쓰는 경우도 있어 숫자가 엇갈립니다. 이 글은 2026년 9월 3일 국회에 제출된 정부안만 기준으로 합니다.</p>

<h2 id="sec-5" style="scroll-margin-top:72px;border-left:6px solid #3d8f6b;padding-left:12px;margin-top:36px;">생산적금융 ISA 신설안, 지금 어디까지 왔나요</h2>

<p>생산적금융 ISA는 국내 상장주식·국내 주식형 펀드·국민성장펀드 등에 투자하는 계좌의 이자·배당소득을 전액 비과세하는 신설 상품이고, 2026년 10월 15일 현재 국회 통과 전입니다.</p>

  <b>아직 확정된 법이 아닙니다</b>
  <p style="margin:8px 0 0 0;">정기국회 심의 과정에서 조건이 바뀌거나 무산될 수 있습니다. 국회 통과 여부는 <a href="https://www.fsc.go.kr" target="_blank" rel="noopener">금융위원회</a> 보도자료에서 확인할 수 있습니다.</p>
</div>

<h2 id="sec-6" style="scroll-margin-top:72px;border-left:6px solid #3d8f6b;padding-left:12px;margin-top:36px;">투자자에게 ISA 한도가 중요한 이유</h2>

<p>ISA의 한도 구조는 "얼마를 어느 계좌에 둘지"를 정하는 기준이 되고, 비과세 한도는 계좌 안 손익을 합친 순소득에 적용됩니다.</p>

<ul style="line-height:1.9;">
  <li>한 상품에서 난 손실은 다른 상품의 이익과 합쳐져 과세 대상이 줄어듭니다(<a href="https://sensitiveboss3.tistory.com/entry/isa-gain-loss-netting">ISA 손익통산 글</a>).</li>
  <li>일반 계좌에서 국내 상장 해외 ETF의 매매차익에 붙는 세금과 ISA 안에서의 세금은 계산 방식이 다릅니다(<a href="https://sensitiveboss3.tistory.com/entry/domestic-listed-overseas-etf-tax">국내상장 해외ETF 세금 글</a>).</li>
  <li>연금 계좌와 한도를 나눠 쓰는 방법은 <a href="https://sensitiveboss3.tistory.com/entry/irp-isa-account-difference">IRP와 ISA 차이 글</a>과 <a href="https://sensitiveboss3.tistory.com/entry/pension-savings-tax-credit">연금저축 세액공제 글</a>에서 이어집니다.</li>
</ul>

<p>한도가 클수록 유리한 것이 아니라, 손익이 한 계좌에 모일수록 비과세 한도를 효율적으로 쓴다는 점이 핵심입니다. 이미 가진 ISA를 다른 금융사로 옮길 때의 한도 처리는 <a href="https://sensitiveboss3.tistory.com/entry/isa-account-transfer-guide">ISA 계좌 이전 글</a>에 있습니다.</p>

<div style="background:#eef8f2;border:2px solid #3d8f6b;border-radius:10px;padding:16px 20px;margin:28px 0;">
  <strong style="color:#245c43;font-size:18px;">남기고 갈 세 가지</strong>
  <ul style="margin:10px 0 0 0;padding-left:20px;line-height:1.9;">
    <li>기존 ISA는 연 2,000만원·총 1억원, 비과세는 일반형 200만원·서민형 400만원입니다.</li>
    <li>못 채운 한도는 이월되지만 총 1억원을 넘길 수 없습니다.</li>
    <li>"연 4천만원 상향"은 2027년 신설 추진 중인 별도 상품 이야기이고 아직 확정이 아닙니다.</li>
  </ul>
</div>

<h2 style="border-left:6px solid #3d8f6b;padding-left:12px;margin-top:36px;">가입 전에 많이 묻는 것들</h2>

<details style="border:1px solid #ddd;border-radius:6px;padding:12px 16px;margin:8px 0;">
  <summary style="font-weight:bold;cursor:pointer;">ISA 계좌 한도는 얼마인가요</summary>
  <p style="margin:10px 0 0 0;">연간 납입한도 2,000만원, 계좌 총한도 1억원입니다. 일반형·서민형·농어민형 모두 같습니다.</p>
</details>
<details style="border:1px solid #ddd;border-radius:6px;padding:12px 16px;margin:8px 0;">
  <summary style="font-weight:bold;cursor:pointer;">ISA 비과세 한도는 얼마인가요</summary>
  <p style="margin:10px 0 0 0;">일반형은 200만원, 서민형·농어민형은 400만원입니다. 초과 순소득에는 9.9%(지방소득세 포함) 분리과세가 붙습니다.</p>
</details>
<details style="border:1px solid #ddd;border-radius:6px;padding:12px 16px;margin:8px 0;">
  <summary style="font-weight:bold;cursor:pointer;">올해 못 채운 납입한도는 사라지나요</summary>
  <p style="margin:10px 0 0 0;">사라지지 않고 다음 해로 이월됩니다. 다만 계좌에 넣을 수 있는 총액은 1억원이 상한입니다.</p>
</details>
<details style="border:1px solid #ddd;border-radius:6px;padding:12px 16px;margin:8px 0;">
  <summary style="font-weight:bold;cursor:pointer;">연 4천만원으로 한도가 올랐다는 말은 사실인가요</summary>
  <p style="margin:10px 0 0 0;">기존 ISA 한도는 그대로입니다. 그 숫자는 2027년 신설이 추진되는 별도 상품과 섞여 퍼진 이야기입니다.</p>
</details>
<details style="border:1px solid #ddd;border-radius:6px;padding:12px 16px;margin:8px 0;">
  <summary style="font-weight:bold;cursor:pointer;">생산적금융 ISA는 확정된 제도인가요</summary>
  <p style="margin:10px 0 0 0;">아니요. 2026년 9월 3일 국회에 제출된 정부안이고 2026년 10월 15일 현재 국회를 통과하지 않았습니다.</p>
</details>
