<p>일 평균은 분기 합계를 날짜로 나눈 평균이라, 실제로 매일 같은 금액이 쌓이는 것은 아닙니다. 1분기 때 언론이 "하루 6,400억 원"이라고 쓴 것도 같은 방식의 계산입니다.</p>

<h2 id="sec-5" style="scroll-margin-top:72px;border-left:6px solid #7048e8;padding-left:12px;margin-top:36px;">잠정 숫자를 읽을 때 놓치기 쉬운 점</h2>

<p>이번 발표는 결산과 외부 감사가 끝나기 전의 잠정실적이라 확정 숫자와 다를 수 있습니다. 2025년 4분기는 잠정 영업이익 20조 원, 이후 전해진 확정 숫자는 20.1조 원이었습니다.</p>

<ul style="line-height:1.9;">
  <li><strong>연결 기준 확인:</strong> 표의 숫자는 자회사를 합친 연결 기준입니다.</li>
  <li><strong>세부 항목 부재:</strong> 잠정실적에는 부문별 이익과 순이익이 없는 경우가 많습니다.</li>
  <li><strong>반올림 차이:</strong> 조 단위로 줄여 쓰는 보도와 억 단위 공시가 섞이면 끝자리가 어긋납니다.</li>
</ul>

<p>세부 숫자가 필요하면 <a href="https://dart.fss.or.kr" target="_blank" rel="noopener">금융감독원 전자공시(DART)</a>에서 삼성전자를 검색해 "연결재무제표 기준 영업(잠정)실적" 공시를 열면 됩니다.</p>

<h2 id="sec-6" style="scroll-margin-top:72px;border-left:6px solid #7048e8;padding-left:12px;margin-top:36px;">영업이익 숫자가 주식 투자자에게 왜 중요한가</h2>

<p>영업이익은 주당순이익(EPS)을 거쳐 PER 같은 가치 지표를 바꾸기 때문에 주식 투자자는 이 숫자를 가장 먼저 봅니다. 다만 주가는 숫자의 크기보다 시장이 미리 예상한 값과의 차이에 더 크게 반응하는 경우가 많습니다.</p>

<ul style="line-height:1.9;">
  <li>이익 경로: 영업이익이 늘면 EPS가 커지고 같은 주가에서 PER이 낮아 보입니다. 계산은 <a href="https://sensitiveboss3.tistory.com/entry/eps-meaning-calculation" target="_blank" rel="noopener">EPS 뜻과 계산 방법</a>과 <a href="https://sensitiveboss3.tistory.com/entry/per-meaning-calculation" target="_blank" rel="noopener">PER 뜻과 계산 방법</a> 글에 있습니다.</li>
  <li>기대 경로: 시장이 이미 높은 숫자를 반영해 두었다면 사상 최대 실적도 평범한 소식이 될 수 있습니다.</li>
  <li>지속성 경로: 영업이익이 한 분기 반짝인지 몇 분기째 이어지는지에 따라 같은 숫자의 해석이 달라집니다.</li>
</ul>

<p>이 표만으로 방향을 단정할 수는 없습니다. 증가율이 낮아지는 흐름과 컨센서스 대비 차이를 함께 놓고 읽어야 합니다.</p>

<div style="background:#fffbeb;border:1px solid #f59e0b;border-radius:8px;padding:14px 18px;margin:16px 0;">
  <strong>💡 우선주 투자자라면</strong>
  <p style="margin:8px 0 0 0;">같은 회사의 보통주와 우선주는 주가가 다르게 움직이는 구간이 있습니다. 이유는 <a href="https://sensitiveboss3.tistory.com/entry/samsung-preferred-stock-gap" target="_blank" rel="noopener">삼성전자 우선주 괴리</a> 글에서 확인할 수 있습니다.</p>
</div>

<h2 id="sec-7" style="scroll-margin-top:72px;border-left:6px solid #7048e8;padding-left:12px;margin-top:36px;">영업이익 얘기 나오면 따라붙는 질문 다섯</h2>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">삼성전자 3분기 영업이익은 얼마였나요?</summary>
  <p style="margin:10px 0 0 0;">연결 기준 107조 4,000억 원입니다. 2026년 10월 8일 잠정실적으로 공시했고, 매출은 195조 원입니다.</p>
</details>
<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">영업이익이 매출액과 어떻게 다른가요?</summary>
  <p style="margin:10px 0 0 0;">매출액은 판 금액 전체이고, 영업이익은 거기서 원가와 판매관리비 같은 본업 비용을 뺀 금액입니다. 3분기는 매출 195조 원 중 107조 4,000억 원이 영업이익으로 남았습니다.</p>
</details>
<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">영업이익 107조 원이면 순이익도 같은가요?</summary>
  <p style="margin:10px 0 0 0;">같지 않습니다. 순이익은 영업이익에서 이자, 세금 같은 항목을 더하고 뺀 뒤의 값이라 잠정실적 첫 발표에는 영업이익만 나오는 경우가 많습니다. 순이익은 사업보고서나 분기보고서에서 확인합니다.</p>
</details>
<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">잠정실적과 나중에 나오는 확정 숫자가 다를 수 있나요?</summary>
  <p style="margin:10px 0 0 0;">조금 다를 수 있습니다. 2025년 4분기는 잠정 영업이익이 20조 원이었고 확정 숫자는 20.1조 원으로 전해졌습니다. 구조는 <a href="https://sensitiveboss3.tistory.com/entry/samsung-earnings-release-guide" target="_blank" rel="noopener">삼성전자 실적발표 잠정과 확정 차이</a> 글에 있습니다.</p>
</details>
<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">시장 예상보다 높았는지는 어디서 보나요?</summary>
  <p style="margin:10px 0 0 0;">컨센서스와 비교해 봅니다. 컨센서스는 증권사 추정치의 평균이고, 출처마다 값이 달라서 비교 기준을 하나로 정해 두는 편이 낫습니다. 읽는 방법은 <a href="https://sensitiveboss3.tistory.com/entry/consensus-estimate-check-guide" target="_blank" rel="noopener">컨센서스 뜻과 확인 방법</a> 글에 정리했습니다.</p>
</details>
