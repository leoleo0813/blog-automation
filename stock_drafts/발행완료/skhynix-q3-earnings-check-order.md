<h2 id="sec-5" style="scroll-margin-top:72px;border-left:6px solid #0ca678;padding-left:12px;margin-top:36px;">발표 당일 실적을 확인하는 다섯 단계</h2>

<p>발표 당일에는 다섯 단계만 밟으면 숫자를 틀리지 않고 읽을 수 있습니다. 보도마다 숫자를 줄여 쓰는 방식이 달라서 순서를 지키는 편이 좋습니다.</p>

<ol style="line-height:1.9;">
  <li>
    <h3 style="font-size:17px;margin:14px 0 4px 0;">1단계: 공시 원문 열기</h3>
    <p style="margin:0;"><a href="https://dart.fss.or.kr" target="_blank" rel="noopener">금융감독원 전자공시(DART)</a>에서 SK하이닉스를 검색해 가장 최근 실적 공시를 엽니다.</p>
  </li>
  <li>
    <h3 style="font-size:17px;margin:14px 0 4px 0;">2단계: 연결 기준인지 보기</h3>
    <p style="margin:0;">기사에 나오는 숫자는 자회사까지 합친 연결 기준입니다. 별도 기준 숫자와 섞이면 비교가 틀어집니다.</p>
  </li>
  <li>
    <h3 style="font-size:17px;margin:14px 0 4px 0;">3단계: 이번 분기와 직전 분기 나란히 놓기</h3>
    <p style="margin:0;">위 표의 2분기 값을 옆에 두고 매출과 영업이익이 각각 얼마나 달라졌는지 계산합니다.</p>
  </li>
  <li>
    <h3 style="font-size:17px;margin:14px 0 4px 0;">4단계: 주주환원 공시 찾기</h3>
    <p style="margin:0;">같은 날 DART에서 배당 결정이나 자기주식 취득 결정 공시가 올라왔는지 봅니다. 금액·기준일·지급일이 공시 본문에 적힙니다.</p>
  </li>
  <li>
    <h3 style="font-size:17px;margin:14px 0 4px 0;">5단계: 시장 예상과 비교하기</h3>
    <p style="margin:0;">위 컨센서스 표의 숫자로 실제÷예상을 계산합니다. 상회·하회 계산법은 <a href="https://sensitiveboss3.tistory.com/entry/consensus-estimate-check-guide" target="_blank" rel="noopener">컨센서스 뜻과 확인 방법</a> 글에 있습니다.</p>
  </li>
</ol>

<h2 id="sec-6" style="scroll-margin-top:72px;border-left:6px solid #0ca678;padding-left:12px;margin-top:36px;">실적 발표가 주식 투자자에게 왜 중요한가</h2>

<p>실적 발표는 기업이 번 돈의 실제 값이 처음 공개되는 순간이라, 시장이 가진 예상이 맞았는지 확인되는 날입니다. 주가가 오를지 내릴지는 정해져 있지 않고, 숫자가 예상과 얼마나 달랐는지가 반응을 만듭니다.</p>

<ul style="line-height:1.9;">
  <li>이익 경로: 영업이익이 늘면 주당순이익(EPS)이 커지고, 같은 주가라도 PER이 낮아 보입니다. 계산은 <a href="https://sensitiveboss3.tistory.com/entry/eps-meaning-calculation" target="_blank" rel="noopener">EPS 뜻과 계산 방법</a> 글에 있습니다.</li>
  <li>기대 경로: 시장이 이미 높은 숫자를 반영해 두었다면 사상 최대 실적도 평범한 소식이 될 수 있습니다. 2분기가 그런 사례로, 보도에서도 "시장 기대치에는 못 미쳤다"는 평가가 붙었습니다.</li>
  <li>주주환원 경로: 자사주를 소각하면 발행주식 수가 줄어 EPS 계산의 분모가 작아집니다. 배당 확대는 같은 이익에서 주주에게 돌아가는 현금을 늘립니다.</li>
  <li>지속성 경로: 영업이익률이 몇 분기째 유지되는지가 일회성 호조인지 구조적 변화인지 가르는 단서입니다.</li>
</ul>

<p>분기 숫자 하나로 방향을 단정하지 말고, 최근 세 분기 흐름과 시장 예상, 주주환원 규모를 함께 놓고 읽으면 됩니다.</p>
