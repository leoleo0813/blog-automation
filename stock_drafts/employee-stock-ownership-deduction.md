<h2 style="border-left:6px solid #059669;padding-left:12px;margin-top:36px;">우리사주 소득공제 받는 조건</h2>

<p>우리사주 소득공제는 근로복지기본법상 우리사주조합원이 조합을 통해 직접 출자한 금액에만 적용됩니다. 회사가 다니는 직장에 우리사주조합이 설립되어 있어야 하고, 급여에서 본인이 실제로 돈을 내서 출자했어야 합니다.</p>

<ul style="margin:10px 0 0 0;padding-left:20px;line-height:1.9;">
  <li>회사에 설립된 우리사주조합의 조합원일 것</li>
  <li>조합을 통해 본인이 직접 출자한 금액일 것(회사·대주주가 무상으로 지급한 우리사주는 제외)</li>
  <li>출자금은 해당 연도 근로소득금액에서만 공제되고, 퇴직소득이나 사업소득에는 적용되지 않을 것</li>

<p>회사나 대주주가 무상으로 나눠준 우리사주는 소득공제를 받을 수 없습니다. 그런데도 인출 시점까지 소득세를 부과하지 않는 과세이연 혜택은 그대로 적용되므로, 무상 지급분이라고 세제 혜택이 아예 없는 것은 아닙니다.</p>

      <td style="border:1px solid #ddd;padding:8px;">출자금액과 1,500만 원 중 적은 금액</td>
      <td style="border:1px solid #ddd;padding:8px;">조세특례제한법 제16조제1항제3호 벤처기업 등 기준 적용</td>
    </tr>
  </tbody>
</table>

<p>공제는 출자한 해의 근로소득에서 바로 빠지는 방식이라, 공제받는 시점에는 세금 부담이 줄어듭니다. 세부 요건은 <a href="https://www.law.go.kr/lsLawLinkInfo.do?lsJoLnkSeq=1001060464&amp;chrClsCd=010202" target="_blank" rel="noopener">국가법령정보센터</a>에서 조문 원문으로 확인할 수 있습니다.</p>

<h2 style="border-left:6px solid #059669;padding-left:12px;margin-top:36px;">우리사주 인출 시 세금 계산법</h2>

<p>우리사주는 낼 때 공제받고 뺄 때(인출 시) 과세하는 구조입니다. 출자할 때 소득공제를 받은 만큼, 나중에 조합에서 주식을 인출하면 그 인출금을 근로소득으로 봅니다.</p>

<p>다만 오래 보유할수록 인출금에 붙는 소득세가 줄어듭니다. <mark>보유기간이 4년 이상이면 인출금의 75%</mark>에 소득세를 부과하지 않고, 중소기업 근로자가 6년 이상 보유하면 인출금 전액에 소득세가 붙지 않습니다.</p>

<p>그런데 회사나 대주주가 무상으로 지급한 우리사주는 애초에 소득공제를 받지 않았으므로, 인출 시에도 이 감면 비율과는 별도로 취급됩니다. 조합기금이나 조합 보유 우리사주에서 생긴 소득 자체에는 소득세가 부과되지 않는 별도 비과세 규정도 있습니다.</p>

<h2 style="border-left:6px solid #059669;padding-left:12px;margin-top:36px;">우리사주 소득공제 계산 예시</h2>

<p>과세표준이 1,400만 원 초과 5,000만 원 이하 구간(세율 15%, 누진공제 126만 원)에 해당하는 근로자를 예로 들어보겠습니다. 이 근로자가 우리사주조합에 300만 원을 출자했다면, 400만 원 한도 안이라 출자금 전액이 소득공제 대상입니다.</p>

<ul style="margin:10px 0 0 0;padding-left:20px;line-height:1.9;">
  <li>소득공제액: 300만 원(한도 400만 원 이내이므로 전액 인정)</li>
  <li>적용 세율: 15%(해당 과세표준 구간)</li>
  <li>줄어드는 소득세: 300만 원 × 15% = 45만 원</li>
  <li>지방소득세(소득세의 10%)까지 더하면 4만 5천 원이 추가로 줄어, 총 절세 효과는 <mark>약 49만 5천 원</mark>입니다.</li>
</ul>

<p>실제 절세액은 개인의 과세표준 구간과 다른 소득공제·세액공제 적용 여부에 따라 달라질 수 있습니다. 정확한 금액은 연말정산 시 회사의 원천징수 결과로 확인하는 것이 가장 정확합니다.</p>

<h2 style="border-left:6px solid #059669;padding-left:12px;margin-top:36px;">연말정산 신청방법과 가입 제외 대상</h2>

<p>우리사주 소득공제는 별도로 국세청에 신청서를 내는 방식이 아니라, 회사가 진행하는 연말정산 절차 안에서 반영됩니다.</p>

<ol style="margin:10px 0 0 0;padding-left:20px;line-height:1.9;">
  <li>재직 중인 회사의 우리사주조합에 가입합니다.</li>
  <li>조합을 통해 우리사주를 취득할 출자금을 납입합니다.</li>
  <li>연말정산 시기에 우리사주조합이 발급하는 <b>우리사주조합출연금액확인서</b>를 받습니다.</li>
  <li>이 확인서를 회사(원천징수의무자)에 제출하면, 회사가 연말정산에서 소득공제를 반영합니다.</li>
</ol>

<p>모든 근로자가 우리사주조합에 가입할 수 있는 것은 아닙니다. 주주총회에서 선임된 임원, 일용근로자, 해당 기업의 대주주는 조합 가입 대상에서 제외됩니다.</p>

<p>제도의 구조와 법적 근거는 <a href="https://www.nts.go.kr" target="_blank" rel="noopener">국세청</a>과 <a href="https://www.moel.go.kr" target="_blank" rel="noopener">고용노동부</a> 홈페이지에서 확인할 수 있습니다.</p>

<h2 style="border-left:6px solid #059669;padding-left:12px;margin-top:36px;">많이 묻는 질문들</h2>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">우리사주 소득공제는 누구나 받을 수 있나요</summary>
  <p style="margin:10px 0 0 0;">아닙니다. 해당 회사의 우리사주조합원이어야 하고, 조합을 통해 본인이 직접 출자한 금액만 공제 대상입니다. 주주총회에서 선임된 임원, 일용근로자, 회사의 대주주는 조합 가입 대상에서 제외됩니다.</p>
</details>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">벤처기업 우리사주 소득공제 한도는 얼마인가요</summary>
  <p style="margin:10px 0 0 0;">벤처기업 등의 우리사주조합원은 출자금액과 1,500만 원 중 적은 금액까지 공제받습니다. 일반 기업 조합원의 한도인 400만 원보다 훨씬 넓습니다.</p>
</details>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">회사가 무상으로 준 우리사주도 소득공제 되나요</summary>
  <p style="margin:10px 0 0 0;">아니요. 회사나 대주주가 출연해 무상으로 취득한 우리사주는 소득공제 대상이 아닙니다. 인출 시점까지 별도 과세 없이 세금이 이연되는 혜택은 그대로 적용됩니다.</p>
</details>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">우리사주를 4년 넘게 보유하면 세금이 얼마나 줄어드나요</summary>
  <p style="margin:10px 0 0 0;">인출금의 75%에 소득세를 부과하지 않습니다. 2년 이상 4년 미만 보유는 50%가 면제되고, 중소기업 근로자가 6년 이상 보유하면 인출금 전액에 소득세가 부과되지 않습니다.</p>
</details>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">연말정산 때 어떤 서류를 내야 하나요</summary>
  <p style="margin:10px 0 0 0;">우리사주조합이 발급하는 우리사주조합출연금액확인서를 회사에 제출하면 됩니다. 이 확인서를 바탕으로 회사가 연말정산에서 소득공제를 반영합니다.</p>
