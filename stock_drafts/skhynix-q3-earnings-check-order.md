<p>1분기는 37조 6,103억 원을 52조 5,763억 원으로 나눠 약 71.5%이고, 두 값의 차이가 약 4.8%포인트입니다. 보도에서 말한 "4%포인트 상승"과 같은 방향의 값입니다.</p>

<p>영업이익이 늘어도 매출이 더 빨리 늘면 이익률은 내려갑니다. <mark>발표 당일에는 영업이익 금액과 영업이익률을 함께 봐야 실적의 질을 알 수 있습니다.</mark></p>

<h2 id="sec-5" style="scroll-margin-top:72px;border-left:6px solid #e8590c;padding-left:12px;margin-top:36px;">실적 발표가 주식 투자자에게 왜 중요한가</h2>

<p>실적 발표는 기업이 번 돈의 실제 값이 처음 공개되는 순간이라, 시장이 가진 예상이 맞았는지 확인되는 날입니다. 주가가 오를지 내릴지는 정해져 있지 않고, 숫자가 예상과 얼마나 달랐는지가 반응을 만듭니다.</p>

<ul style="line-height:1.9;">
  <li>이익 경로: 영업이익이 늘면 주당순이익(EPS)이 커지고, 같은 주가라도 PER이 낮아 보입니다. EPS 계산은 <a href="https://sensitiveboss3.tistory.com/entry/eps-meaning-calculation" target="_blank" rel="noopener">EPS 뜻과 계산 방법</a> 글에 있습니다.</li>
  <li>기대 경로: 시장이 이미 높은 숫자를 반영해 두었다면 사상 최대 실적도 평범한 소식이 될 수 있습니다.</li>
  <li>지속성 경로: 영업이익률이 몇 분기째 유지되는지가 일회성 호조인지 구조적 변화인지 가르는 단서입니다.</li>
</ul>

<p>분기 숫자 하나로 방향을 단정하지 말고, 최근 세 분기 흐름과 시장 예상을 함께 놓고 읽으면 됩니다.</p>

<div style="background:#fffbeb;border:1px solid #f59e0b;border-radius:8px;padding:14px 18px;margin:16px 0;">
  <strong>💡 한 가지만 더</strong>
  <p style="margin:8px 0 0 0;">같은 시기에 발표되는 삼성전자 실적도 같은 방식으로 읽습니다. 잠정과 확정이 나뉘는 구조는 <a href="https://sensitiveboss3.tistory.com/entry/samsung-earnings-release-guide" target="_blank" rel="noopener">삼성전자 실적발표 잠정과 확정 차이</a> 글에서 볼 수 있습니다.</p>
</div>

<h2 id="sec-6" style="scroll-margin-top:72px;border-left:6px solid #e8590c;padding-left:12px;margin-top:36px;">숫자를 읽다 보면 붙는 물음 여섯</h2>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">SK하이닉스 3분기 실적은 언제 나오나요?</summary>
  <p style="margin:10px 0 0 0;">2026년 10월 6일 현재 회사가 확정해 알린 날짜는 확인되지 않습니다. 지난해 3분기는 10월 29일, 올해 2분기는 7월 29일에 발표됐고, 정리 사이트 한 곳은 10월 27일로 적고 있습니다.</p>
</details>
<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">2분기 영업이익은 얼마였나요?</summary>
  <p style="margin:10px 0 0 0;">60조 5,426억 원입니다. 매출액은 79조 3,187억 원이고, 둘 다 분기 기준 역대 최대로 보도됐습니다.</p>
</details>
<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">영업이익률은 어떻게 구하나요?</summary>
  <p style="margin:10px 0 0 0;">영업이익을 매출액으로 나눠 100을 곱합니다. 2분기는 60조 5,426억 원을 79조 3,187억 원으로 나눠 약 76.3%이고, 보도에서 밝힌 76%와 같습니다.</p>
</details>
<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">잠정실적과 확정실적은 뭐가 다른가요?</summary>
  <p style="margin:10px 0 0 0;">삼성전자처럼 먼저 숫자를 공시하는 회사는 잠정이 먼저 나오고 뒤에 확정이 따라옵니다. 삼성전자 쪽 차이는 <a href="https://sensitiveboss3.tistory.com/entry/samsung-earnings-release-guide" target="_blank" rel="noopener">삼성전자 실적발표 잠정과 확정 차이</a> 글에 정리해 두었습니다.</p>
</details>
<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">분기보고서는 언제까지 나오나요?</summary>
  <p style="margin:10px 0 0 0;">분기 종료 후 45일 이내에 제출해야 합니다. 3분기 분기보고서는 11월 14일이 토요일이라 11월 16일(월)까지로 계산됩니다.</p>
</details>
<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">실적이 좋으면 주가도 오르나요?</summary>
  <p style="margin:10px 0 0 0;">단정할 수 없습니다. 주가는 숫자 자체보다 시장이 미리 예상한 값과의 차이에 반응하는 경우가 많아서, 사상 최대 실적에도 예상에 못 미치면 다르게 움직일 수 있습니다.</p>
</details>
