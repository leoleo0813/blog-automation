<p style="font-size:13px;color:#888;">출처: <a href="https://www.nts.go.kr/nts/cm/cntnts/cntntsView.do?cntntsId=8800&amp;mi=12274" target="_blank" rel="noopener">국세청 「주식등 양도소득세 - 세액계산요령」</a>, 2024-01-01 이후 양도분 기준(2026-09-07 원문 대조). 금액 50억원 유지는 2025-09-15 정부 발표(<a href="https://biz.sbs.co.kr/amp/article/20000259536" target="_blank" rel="noopener">SBS Biz</a>, <a href="https://www.jjan.kr/articleAmp/20250915580012" target="_blank" rel="noopener">전북도민일보</a> 보도). K-OTC 벤처기업 주식은 지분율 4% 또는 40억원이 별도 기준입니다.</p>

<h2 id="sec-2" style="scroll-margin-top:72px;border-left:6px solid #2e8b57;padding-left:12px;margin-top:36px;">내 보유금액이 50억원을 넘는지 계산하는 법</h2>

<p><mark>보유금액은 판정일의 주가에 본인과 특수관계인의 주식 수를 합쳐 곱한 값입니다.</mark> 지분율과 금액 중 하나만 기준을 넘어도 대주주가 됩니다.</p>

<div style="background:#f6f6f4;border-left:4px solid #999;padding:14px 18px;margin:20px 0;">
  <b>가상 사례: 코스피 종목 하나, 12월 31일 종가 8만원</b>
  <ul style="margin:8px 0 0 0;padding-left:20px;line-height:1.9;">
    <li>본인 60,000주 × 80,000원 = 48억원 (50억원 미만)</li>
    <li>배우자 10,000주 × 80,000원 = 8억원</li>
    <li>합산 70,000주 × 80,000원 = <b>56억원</b>, 50억원 이상이라 두 사람 모두 대주주</li>
  </ul>
</div>

<p>본인 몫만 보면 기준 아래인데 가족 지분을 더하면 넘는 경우가 이 사례입니다. 반대로 주가가 낮아 금액은 미달이어도 지분율이 1%(코스피)를 넘으면 금액과 무관하게 대주주입니다.</p>

<ul style="line-height:1.9;padding-left:20px;">
  <li>보유금액 = (본인 + 특수관계인 주식 수) × 판정일 주가</li>
  <li>지분율 = (본인 + 특수관계인 주식 수) ÷ 발행주식 총수</li>
  <li>종목마다 따로 계산합니다. 서로 다른 종목의 보유금액은 합치지 않습니다.</li>
</ul>

<h2 id="sec-3" style="scroll-margin-top:72px;border-left:6px solid #2e8b57;padding-left:12px;margin-top:36px;">기준은 언제 바뀌었고 10억원 환원안은 어떻게 됐나</h2>

<p><mark>금액 기준은 2020년 4월에 코스피 10억원까지 내려갔다가 2024년 1월부터 50억원으로 올랐고, </mark>2025년 9월 정부가 10억원 환원 계획을 접으면서 지금도 50억원입니다. 정부는 2025년 7월 말 세제개편안에서 종목당 50억원을 10억원으로 낮추려 했지만, 투자자 반발과 당정 협의를 거쳐 9월 15일 현행 유지로 정리했습니다.</p>

</div>

<h2 id="sec-4" style="scroll-margin-top:72px;border-left:6px solid #2e8b57;padding-left:12px;margin-top:36px;">대주주 판정일과 신고 일정</h2>

<p>대주주 여부는 주식을 파는 날이 아니라 양도일이 속한 연도의 <mark>전년도 12월 31일(직전 사업연도 종료일) 보유 상태</mark>로 판정합니다. 12월 결산 상장사라면 2026년에 파는 주식은 2025년 12월 31일, 2027년에 파는 주식은 2026년 12월 31일 기준입니다.</p>

<figure style="margin:24px 0;"><img src="https://raw.githubusercontent.com/leoleo0813/blog-automation/main/assets/figures/stock-capital-gains-tax-target-2.png" alt="2026년 양도분은 2025년 12월 31일, 2027년 양도분은 2026년 12월 31일 보유금액으로 판정하고 예정신고 8월 31일, 확정신고 2027년 5월" style="max-width:100%;"><figcaption style="font-size:13px;color:#888;">자료: 국세청 대주주 요건·신고 일정</figcaption></figure>

<ul style="line-height:1.9;padding-left:20px;">
  <li>그 날에는 기준 미달이어도 해당 연도 중에 주식을 더 사서 지분율이 기준을 넘으면, 취득일 이후부터 대주주입니다.</li>
  <li>대주주가 2026년 상반기에 판 주식은 8월 31일까지, 하반기에 판 주식은 2027년 2월 말까지 예정신고·납부합니다.</li>
  <li>확정신고는 다음 해 5월 1일부터 31일까지입니다. 신고 절차는 <a href="https://sensitiveboss3.tistory.com/entry/domestic-stock-capital-gains-filing" target="_blank" rel="noopener">국내주식 양도소득세 신고방법</a> 글에, 세액이 클 때 나눠 내는 방법은 <a href="https://sensitiveboss3.tistory.com/entry/capital-gains-tax-installment-payment" target="_blank" rel="noopener">양도소득세 분납</a> 글에 정리했습니다.</li>
</ul>

<h2 id="sec-5" style="scroll-margin-top:72px;border-left:6px solid #2e8b57;padding-left:12px;margin-top:36px;">대주주 기준은 주식 투자자에게 왜 중요한가</h2>

<p>판정일이 12월 31일로 고정돼 있어서, 기준이 강화될 때마다 연말 직전에 보유금액을 줄이려는 매도가 나올 수 있다는 우려가 보도에 따라붙었습니다. 2025년 7월 10억원 환원안이 나왔을 때도 투자자 청원과 반발이 커졌고, 정부는 "자본시장 활성화"를 이유로 한 달 반 만에 유지를 택했습니다.</p>

<ul style="line-height:1.9;padding-left:20px;">
  <li>해당자는 소수입니다. 한 종목에 50억원 이상 가진 사람이 대주주라, 대부분의 개인은 해당하지 않습니다.</li>
  <li>기준이 내려가면 해당자가 늘어 연말 매도 물량 우려로 이어질 수 있고, 올라가거나 유지되면 그 우려가 줄어드는 쪽으로 읽힙니다.</li>
  <li>다만 이것이 주가의 방향을 정해 주지는 않습니다. 같은 해에도 실적·금리·환율이 더 크게 움직이는 경우가 많습니다.</li>
</ul>

<p>대주주가 아니어도 팔 때는 증권거래세가 붙습니다. 2026년 시장별 세율과 100만원당 금액은 <a href="https://sensitiveboss3.tistory.com/entry/securities-transaction-tax-rate" target="_blank" rel="noopener">증권거래세 세율 2026</a> 글에서 한 표로 볼 수 있고, 양도세까지 합친 계산은 <a href="https://sensitiveboss3.tistory.com/entry/stock-sell-tax-amount" target="_blank" rel="noopener">주식 매도 세금 얼마</a> 글에 있습니다.</p>

<h2 id="sec-6" style="scroll-margin-top:72px;border-left:6px solid #2e8b57;padding-left:12px;margin-top:36px;">소액주주도 세금을 내는 예외</h2>

<p>대주주가 아니어도 증권시장 밖에서 거래하거나 비상장주식을 팔면 양도소득세 대상입니다. 이 두 경우는 대주주 요건과 무관하게 과세됩니다.</p>

<div style="background:#f6f6f4;border-left:4px solid #999;padding:14px 18px;margin:20px 0;">
  <b>과세 여부 한눈 정리</b>
  <ul style="margin:8px 0 0 0;padding-left:20px;line-height:1.9;">
    <li>소액주주 + 증권시장 안 거래: 양도소득세 없음</li>
    <li>대주주: 1주만 팔아도 과세</li>
    <li>소액주주라도 증권시장 밖 거래: 과세</li>
    <li>비상장주식: 대주주·소액주주 구분 없이 과세(K-OTC 중소·중견기업 주식 양도는 제외)</li>
  </ul>
</div>

<p>해외주식은 대주주 요건 자체가 적용되지 않습니다. 대주주 여부와 무관하게 연 250만원을 넘는 차익에 세금이 붙고, 신고 방법은 <a href="https://sensitiveboss3.tistory.com/entry/overseas-stock-tax-filing" target="_blank" rel="noopener">해외주식 양도소득세 신고 방법</a> 글에 있습니다.</p>

<div style="background:#eef7f1;border:2px solid #2e8b57;border-radius:10px;padding:16px 20px;margin:28px 0;">
  <strong style="color:#1f5c3b;font-size:18px;">정리하면</strong>
  <ul style="margin:10px 0 0 0;padding-left:20px;line-height:1.9;">
    <li>한 종목 보유금액 50억원 또는 지분율(코스피 1%·코스닥 2%·코넥스 4%) 중 하나만 넘으면 대주주입니다.</li>
    <li>판정은 전년도 12월 31일 보유금액이고, 배우자·직계존비속 지분이 합산됩니다.</li>
    <li>10억원 환원안은 2025년 9월 철회됐고, 연말 세제 개정 발표가 나오면 기준이 바뀌었는지 먼저 봐야 합니다.</li>
  </ul>
</div>

<h2 style="border-left:6px solid #2e8b57;padding-left:12px;margin-top:36px;">대주주 문의에서 반복되는 질문</h2>

<details style="border:1px solid #ddd;border-radius:6px;padding:12px 16px;margin:8px 0;">
  <summary style="font-weight:bold;cursor:pointer;">2026년 대주주 기준은 10억원인가요, 50억원인가요</summary>
  <p style="margin:10px 0 0 0;">50억원입니다. 2025년 7월에 10억원으로 낮추는 안이 나왔지만 2025년 9월 15일 현행 50억원 유지로 정리됐습니다. 비상장주식만 10억원입니다.</p>
</details>

<details style="border:1px solid #ddd;border-radius:6px;padding:12px 16px;margin:8px 0;">
  <summary style="font-weight:bold;cursor:pointer;">여러 종목을 합쳐 50억원이 넘으면 대주주인가요</summary>
  <p style="margin:10px 0 0 0;">아닙니다. 종목마다 따로 계산합니다. 한 종목에서 본인과 특수관계인 보유금액이 50억원 이상이어야 그 종목의 대주주입니다.</p>
</details>

<details style="border:1px solid #ddd;border-radius:6px;padding:12px 16px;margin:8px 0;">
  <summary style="font-weight:bold;cursor:pointer;">배우자나 자녀 주식도 합산하나요</summary>
  <p style="margin:10px 0 0 0;">네. 본인과 특수관계인의 지분을 합산해 판정합니다. 앞의 가상 사례처럼 본인 몫만 보면 미달이어도 가족 지분을 더하면 기준을 넘을 수 있습니다.</p>
</details>

<details style="border:1px solid #ddd;border-radius:6px;padding:12px 16px;margin:8px 0;">
  <summary style="font-weight:bold;cursor:pointer;">12월 31일 이후 팔면 대주주 판정이 달라지나요</summary>
  <p style="margin:10px 0 0 0;">판정일은 전년도 12월 31일로 고정이라 해가 바뀐 뒤 판다고 달라지지 않습니다. 2027년에 파는 주식의 판정일은 2026년 12월 31일입니다.</p>
</details>

<details style="border:1px solid #ddd;border-radius:6px;padding:12px 16px;margin:8px 0;">
  <summary style="font-weight:bold;cursor:pointer;">소액주주는 주식을 팔 때 세금이 전혀 없나요</summary>
  <p style="margin:10px 0 0 0;">양도소득세는 없지만 증권거래세는 냅니다. 증권시장 안에서 파는 국내 상장주식 소액주주는 양도소득세 대상이 아닙니다.</p>
</details>

<details style="border:1px solid #ddd;border-radius:6px;padding:12px 16px;margin:8px 0;">
  <summary style="font-weight:bold;cursor:pointer;">비상장주식은 대주주가 아니어도 세금을 내나요</summary>
  <p style="margin:10px 0 0 0;">네. 비상장주식은 대주주·소액주주 구분 없이 양도소득세 과세 대상입니다. K-OTC를 통한 중소·중견기업 주식 양도는 제외됩니다.</p>
</details>
