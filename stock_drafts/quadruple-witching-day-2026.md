  <li>프로그램 매매 청산 물량이 매도 쪽으로 쏠리면 하락 압력, 매수 쪽으로 쏠리면 상승 압력이 생깁니다.</li>
  <li>장 마감 동시호가 시간대에 거래량이 튀는 경우가 흔합니다. 특정 종목이 유독 크게 움직이면 기업 가치 변화보다 만기 청산 물량 탓일 수 있습니다.</li>
  <li>외국인 순매도액만으로 방향을 짐작하기 어렵습니다. 올해 세 번 모두 1조 8천억 원 이상 팔았지만 종가 변동은 0.5% 안쪽이었습니다.</li>
  <li>지수 정기변경처럼 같은 날 겹치는 일정이 있으면 수급이 더 커집니다. 9월 10일에는 KRX 섹터지수 변경이 겹쳤다는 보도가 있었습니다.</li>
</ul>

<p>투자자별 순매매는 <a href="https://data.krx.co.kr" target="_blank" rel="noopener">한국거래소 정보데이터시스템</a>의 투자자별 매매동향 메뉴에서 날짜를 골라 볼 수 있습니다.</p>

<h2 id="sec-7" style="scroll-margin-top:72px;border-left:6px solid #d97706;padding-left:12px;margin-top:36px;">만기일 확인하는 법</h2>

<p>다음 네마녀의 날이 정확히 언제인지는 <a href="https://www.krx.co.kr" target="_blank" rel="noopener">한국거래소</a> 홈페이지나 <a href="https://data.krx.co.kr" target="_blank" rel="noopener">정보데이터시스템</a>의 파생상품 결제월 일정에서 볼 수 있습니다.</p>

<ul style="margin:10px 0 0 0;padding-left:20px;line-height:1.9;">
  <li>대부분의 증권사 MTS 앱도 캘린더나 증시 일정 메뉴에서 선물·옵션 만기일을 함께 안내합니다</li>
  <li>이 글의 날짜는 "둘째주 목요일" 규칙을 달력에 적용한 값이고, 2026년 3월·9월 날짜는 언론 보도와도 맞았습니다. 거래소 발표로 바뀔 가능성은 낮습니다</li>
</ul>

<div style="background:#fff8e6;border:2px solid #d97706;border-radius:10px;padding:16px 20px;margin:24px 0;">
  <strong style="color:#92400e;font-size:18px;">요약하면 이렇습니다</strong>
  <ul style="margin:10px 0 0 0;padding-left:20px;line-height:1.8;">
    <li>한국의 남은 네마녀의 날은 12월 10일(목), 미국은 12월 18일(금)입니다.</li>
    <li>올해 세 번은 종가 등락 0.5% 안쪽, 외국인 순매도 1조 8천억 원 이상이었습니다.</li>
    <li>변동성이 커질 수는 있어도 주가 방향이 정해져 있는 날은 아닙니다.</li>
  </ul>
</div>

<h2 id="sec-8" style="scroll-margin-top:72px;border-left:6px solid #d97706;padding-left:12px;margin-top:36px;">궁금한 점 모아보기</h2>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">네마녀의 날에 주식을 사거나 팔면 안 되나요</summary>
  <p style="margin:10px 0 0 0;">거래 자체에는 아무 제약이 없습니다. 다만 장 마감 무렵 거래량이 평소보다 크게 출렁일 수 있으니, 그 변동이 기업 가치 변화가 아니라 만기 청산 때문일 수 있다는 점을 염두에 두면 됩니다.</p>
</details>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">다음 네마녀의 날은 정확히 언제인가요</summary>
  <p style="margin:10px 0 0 0;">2026년 12월 10일 목요일입니다. 2026년 10월 10일 기준으로 61일 뒤이고, 그다음은 2027년 3월 11일입니다.</p>
</details>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">지난 네마녀의 날에 코스피는 얼마나 움직였나요</summary>
  <p style="margin:10px 0 0 0;">올해 세 번은 종가 기준으로 3월 12일 0.48% 하락, 6월 11일 0.43% 상승, 9월 10일 0.25% 하락이었습니다. 세 번 모두 외국인은 코스피에서 1조 8천억 원 넘게 순매도했습니다.</p>
</details>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">왜 하필 목요일인가요</summary>
  <p style="margin:10px 0 0 0;">한국 옵션시장의 만기일 규정 자체가 매월 둘째주 목요일로 정해져 있고, 선물 만기도 분기 말인 3·6·9·12월의 같은 날로 겹치도록 운영되기 때문입니다.</p>
</details>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">미국 네마녀의 날과 한국 네마녀의 날이 겹치는 날도 있나요</summary>
  <p style="margin:10px 0 0 0;">정확히 같은 날인 경우는 없습니다. 한국은 둘째주 목요일, 미국은 셋째주 금요일이라 보통 일주일 정도 차이가 납니다.</p>
</details>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">개인 투자자도 만기일을 신경 써야 하나요</summary>
  <p style="margin:10px 0 0 0;">장기 투자자라면 크게 신경 쓰지 않아도 됩니다. 다만 단기로 매매하거나 특정 종목의 급격한 가격 변동에 놀랄 수 있는 시기라는 정도는 미리 알아 두는 편이 좋습니다.</p>
</details>
