<h2 style="border-left:6px solid #4a90d9;padding-left:12px;margin-top:36px;">곱버스가 정확히 뭔가요</h2>

<p><b>곱버스</b>는 "곱하기+인버스"의 줄임말로, <span style="background:linear-gradient(transparent 60%, #fff3b0 60%);font-weight:bold;">코스피200 선물지수의 하루 수익률을 -2배로 추종하는 ETF·ETN</span>을 말합니다. 대표 상품이 KODEX 200선물인버스2X입니다.</p>

<p>지수가 하루에 1% 떨어지면 곱버스는 약 +2% 오르고, 반대로 지수가 1% 오르면 곱버스는 약 -2% 손실을 봅니다. 이 배수는 <b>매일 새로 계산</b>됩니다.</p>

<h2 style="border-left:6px solid #4a90d9;padding-left:12px;margin-top:36px;">왜 그렇게 위험하다는 말이 나오나요</h2>

<p>매일의 수익률이 복리로 쌓이기 때문에, <mark>지수가 결국 원래 가격으로 돌아와도 곱버스는 원금을 회복하지 못하는</mark> 현상이 생깁니다. 이를 변동성 손실(음의 복리효과)이라고 부릅니다.</p>

<div style="background:#fff8e6;border-left:4px solid #e0a83f;padding:14px 18px;margin:20px 0;line-height:1.8;">
  <b>단순화한 계산 예시 (수수료·괴리율 제외, 실제 상품 수익률 아님)</b>
  <p style="margin:8px 0 0 0;">지수·곱버스 모두 100에서 시작한다고 가정합니다.</p>
  <ul style="margin:8px 0 0 0;padding-left:20px;">
    <li>1일차: 지수 -10%(100→90). 곱버스는 +20%(100→120)</li>
    <li>2일차: 지수 +11.11%(90→100, <b>지수는 정확히 원점 복귀</b>). 곱버스는 -22.22%(120→93.3)</li>
  </ul>
  <p style="margin:8px 0 0 0;">지수는 이틀 만에 <b>0% 변동</b>으로 원래 자리에 돌아왔지만, 곱버스는 <mark>100 → 93.3으로 6.7% 손실</mark>이 남았습니다. 방향을 맞혀도 오르내림이 반복되면 손해가 날 수 있는 이유입니다.</p>
</div>

<p>그래서 곱버스는 방향성이 뚜렷한 단기 구간에서만 짧게 활용하는 상품이지, 오래 들고 있을수록 유리해지는 상품이 아닙니다.</p>

<h2 style="border-left:6px solid #4a90d9;padding-left:12px;margin-top:36px;">투자 전에 뭘 확인해야 하나요</h2>

<p>매매하려는 증권사 앱의 상품 상세 화면에서 <b>기본예탁금 충족 여부</b>를 바로 확인할 수 있고, 사전교육 이수번호는 <a href="https://www.kifin.or.kr/common/edu/1/detail.do" target="_blank" rel="noopener">금융투자교육원</a> 홈페이지에서 발급받아 증권사 계좌에 등록하면 됩니다. 기본예탁금 제도의 구체적인 산정 기준(원화예수금·외화예수금 합산 등)은 <a href="https://www.trueetn.com/trueetn/nkis/invest/invEtn.jsp?cmd=FR13000" target="_blank" rel="noopener">한국투자증권 TRUE ETN 안내 페이지</a>처럼 각 증권사 공지에서 확인하는 것이 정확합니다.</p>

<h2 style="border-left:6px solid #4a90d9;padding-left:12px;margin-top:36px;">자주 묻는 질문</h2>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">곱버스와 인버스는 같은 건가요</summary>
  <p style="margin:10px 0 0 0;">아닙니다. 인버스는 지수 수익률을 -1배로 추종하고, 곱버스는 여기에 레버리지를 더해 -2배로 추종합니다.</p>
</details>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">곱버스는 아무나 살 수 있나요</summary>
  <p style="margin:10px 0 0 0;">아닙니다. 2020년 9월부터 개인 일반투자자는 기본예탁금 1,000만원과 사전교육 1시간 이수가 필요합니다.</p>
</details>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">지수가 원래대로 돌아오면 곱버스도 원금이 회복되나요</summary>
  <p style="margin:10px 0 0 0;">아닙니다. 매일 수익률이 복리로 쌓이는 변동성 손실 때문에, 지수가 정확히 원점으로 돌아와도 곱버스는 손실이 남을 수 있습니다.</p>
</details>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">단일종목 레버리지 ETF도 곱버스인가요</summary>
  <p style="margin:10px 0 0 0;">아닙니다. 곱버스는 코스피200 같은 지수를 추종하고, 단일종목 레버리지 ETF는 삼성전자·테슬라 같은 개별 종목을 추종하는 별개 상품입니다. 예탁금·교육 기준도 더 강화돼 있습니다.</p>
</details>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">단일종목 레버리지 ETF 예탁금은 얼마인가요</summary>
  <p style="margin:10px 0 0 0;">2026년 7월 31일부터 3,000만원으로 상향됐습니다(그 전에는 1,000만원). 대용증권은 인정되지 않고 현금만 인정됩니다.</p>
</details>

<details style="border:1px solid #ddd;border-radius:8px;padding:12px 16px;margin:10px 0;">
  <summary style="font-weight:bold;cursor:pointer;">사전교육은 어디서 받나요</summary>
  <p style="margin:10px 0 0 0;">금융투자교육원(kifin.or.kr) 홈페이지에서 온라인으로 수강하고 이수번호를 발급받아 매매하려는 증권사 계좌에 등록하면 됩니다.</p>
</details>
